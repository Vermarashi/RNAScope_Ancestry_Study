# RNAScope-Ancestry Study

Scripts for the RNAScope-Ancestry study in collaboration with Dr. Robert Meller.

This repository contains the main scripts used in the preparation of the RNAScope-Ancestry paper.

The scripts cover the genetic ancestry analysis of RNA-seq data, including variant filtering, common variant selection, LD pruning, PCA, ancestry inference, and comparison with 1000 Genomes reference populations. Additional scripts cover sub-ancestry analysis and the relationship between genetic ancestry and gene expression.

The ancestry estimates were also compared with ADMIXTURE and validated using a publicly available MAGE dataset.

Raw data will be available through dbGaP. Sample information is not included in this repository because it contains sensitive participant information.

The initial RNA-seq processing and GATK variant-calling pipeline was developed in collaboration with Dr. Robert Meller and colleagues. The scripts in this repository cover the subsequent genetic ancestry analysis performed for the RNAScope-Ancestry study.
